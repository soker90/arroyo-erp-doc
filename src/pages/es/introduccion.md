# Bienvenido a Arroyo ERP

Arroyo ERP es una aplicación web de gestión administrativa orientada a pequeñas empresas. Su interfaz reúne operaciones relacionadas con clientes, proveedores, productos, albaranes, facturas, pagos y consultas de facturación.

El proyecto está publicado como software libre. Consulta el repositorio y el archivo de licencia para conocer los términos exactos de la versión que vayas a utilizar.

- [Código del cliente web](https://github.com/soker90/arroyo-erp-client)
- [Código de la API](https://github.com/soker90/arroyo-erp-api)
- [Modelos de datos](https://github.com/soker90/arroyo-erp-models)
- [Repositorio de documentación](https://github.com/soker90/arroyo-erp-doc)

## ¿Qué encontrarás aquí?

Esta documentación está organizada en dos recorridos:

- **Guía de usuario:** explica las pantallas y los flujos de trabajo con un lenguaje práctico.
- **Guía técnica:** explica cómo preparar una instalación propia, configurar sus servicios y mantenerla.

No necesitas conocimientos de programación para seguir la guía de usuario. Para instalar y administrar una instancia sí necesitarás familiaridad con servidores, contenedores o Node.js, según el método elegido.

## Antes de empezar

Arroyo es una aplicación que debe desplegarse y configurarse con una API y una base de datos compatibles. No des por hecho que existe un servicio público al que registrarse: consulta con la persona que administra tu instalación para obtener la dirección y las credenciales.

## Aviso sobre esta documentación

La documentación se está ampliando a partir del código fuente y de las pantallas existentes. Cuando una operación requiera confirmar un comportamiento visual o una decisión funcional, la página lo indicará expresamente. Los recuadros **[CAPTURA PENDIENTE]** señalan dónde debe insertarse una captura real, tomada de una instancia de prueba y anonimizada antes de publicarla.
