# Facturación e informes

El código incluye operaciones de facturación agrupada, consulta de totales y exportación de información. El nombre de cada informe, sus filtros y el formato generado deben confirmarse en la interfaz actual.

## Facturación de proveedores

La API dispone de un área de facturación agrupada de proveedores. Utiliza los filtros visibles para seleccionar el periodo y los documentos que correspondan.

## Facturación de clientes

La aplicación incluye consultas y exportaciones relacionadas con facturas de clientes.

## Exportar información

1. Selecciona el periodo y los criterios disponibles.
2. Revisa la selección antes de exportar.
3. Descarga el archivo generado.
4. Ábrelo y comprueba que contiene los datos esperados y que las cifras cuadran con los documentos de origen.

**[CAPTURA PENDIENTE — acción de exportación y archivo resultante]**

No se debe dar por supuesto un formato de archivo o una estructura de columnas sin comprobar el resultado real. Trata las exportaciones como información sensible y guárdalas en una ubicación autorizada.
