# Glosario

- **API:** servicio que recibe peticiones del cliente web y ejecuta operaciones de la aplicación.
- **Albarán:** documento que detalla una entrega de productos o servicios.
- **Base de datos:** sistema que conserva los registros de la aplicación; Arroyo utiliza MongoDB.
- **Cliente:** persona o empresa a la que se venden productos o servicios.
- **ERP:** sistema de planificación y gestión de recursos empresariales.
- **Factura:** documento que refleja una operación y sus importes.
- **Factura de cliente:** factura relacionada con una venta a un cliente.
- **Factura recibida:** factura procedente de un proveedor.
- **Frontend / cliente web:** parte de la aplicación que se ejecuta en el navegador.
- **Instancia:** instalación concreta de Arroyo, con su propia configuración y datos.
- **Modelo:** definición de la estructura y comportamiento de un tipo de registro de datos.
- **MongoDB:** base de datos documental usada por Arroyo.
- **Mongoose:** biblioteca que permite trabajar con MongoDB desde Node.js.
- **Proveedor:** persona o empresa que suministra productos o servicios.
- **SPA:** aplicación web que carga una interfaz y cambia de vistas sin recargar cada página desde el servidor.
- **Token:** credencial digital usada para identificar o autorizar una sesión o petición.
- **VITE_*:** variables que Vite incorpora al cliente web durante la compilación; no deben contener secretos.
